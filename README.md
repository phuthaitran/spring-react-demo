# My Web App

Full-stack web application using Spring Boot, React, and MySQL.

## Tech Stack

- **Backend**: Spring Boot, Java
- **Frontend**: React
- **Database**: MySQL

## Getting Started

### Prerequisites
- Java 11+
- Node.js 14+
- MySQL 8+

### Backend Setup
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

## Project Structure
- `/backend` - Spring Boot REST API
- `/frontend` - React application
